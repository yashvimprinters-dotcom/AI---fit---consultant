# FITORA v30 — Build 3 Looks UI Upgrade

This release keeps the v29 security hardening and upgrades the AI Personal Stylist / Build 3 Looks experience for mobile customers.

## What changed
- Replaced the dense text-only look cards with compact visual outfit cards.
- Each look now shows four clear pieces: Top, Bottom, Shoes and Extras.
- Added an occasion badge and a short "Why it works" explanation.
- Added **Try this look** to push the selected look directly into the existing Visual Try-On controls.
- Added **Change one item** so customers can select a look and then adjust footwear/accessories without rebuilding from scratch.
- Added a collapsible Style Preferences area to keep the main mobile screen clean.
- Added safe HTML escaping for AI-returned look values in this UI.
- Preserved the existing v29 security controls, API key handling, rate limiting and image validation.

## Note about product imagery
The current catalog contains demo visual identifiers/emoji rather than licensed retailer photography. Production product cards should use owned or licensed product images.
