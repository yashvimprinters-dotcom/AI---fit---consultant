# v16 Exact Look Builder

v16 adds a component-based look builder:
- select top, bottom, outerwear, footwear and accessory independently
- preview the selected combination as a structured look
- send the exact combination to the visual try-on event
- keep the rest of the outfit unchanged when a single component is swapped

The included catalog is a demo taxonomy with local icons. Production retailer images should be licensed/owned product images with SKU metadata rather than scraped images.
