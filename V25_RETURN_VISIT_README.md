# FITORA v25 — useful repeat visits

V25 keeps the customer journey simple while adding reasons to return:

- Daily FITORA style idea that changes by day.
- One-tap "Use this idea" to seed the styling flow.
- Quick occasion chips (Everyday, Work, Party, Wedding, Date night, Travel).
- "Continue where you left off" on later visits.
- Saved-look count is surfaced when returning.
- All of the existing v24 adaptive themes and FITORA features are preserved.

This is intentionally local-first for the prototype. It does not send marketing notifications or use dark patterns. For production, connect accounts and cloud-saved looks so the same experience follows the customer across devices.
