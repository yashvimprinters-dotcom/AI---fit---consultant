# FITORA v24 — Adaptive Customer Themes

- Sign-up/profile now asks for Fashion section: Men, Women, or Unisex.
- Automatic theme: Men → Ocean Blue; Women → FITORA Purple/Pink; Unisex → Neutral.
- Customers can override the theme in Settings → Appearance.
- Theme affects the app background, hero accents, buttons, section accents and navigation styling.
- Existing FITORA v23 functionality is preserved.
- Profile/theme preferences are stored locally in the browser in this prototype.
