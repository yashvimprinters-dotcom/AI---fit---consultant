# FITORA v23 — Customer-first interface

This version keeps the existing FITORA sizing, styling, exact-product try-on, saved looks, feedback, settings, and account functionality from v22.

## Interface updates
- FITORA brand/logo retained.
- Purple/pink premium fashion visual language.
- Two large side-by-side primary tabs remain: Clothes Fitting and Colour & Visual Try-On.
- Home actions are presented as three large, simple cards:
  - Find My Size
  - Build My Look
  - Try It On
- Account actions remain accessible through My Account & More.
- Added a compact trust/features row and a simple customer guidance message.
- Bottom navigation remains Home / Saved / Account.
- Mobile spacing, buttons, upload area, cards and gradients are optimized for phone use.

## Deployment
Upload the contents of this ZIP at repository root. Keep `requirements.txt` and `app.py` at root.
